# ENT-L09b-0016 — mensagem que a página do preview envia ao editor numa tecla

## Passos
1. `src/editor/shell/preview.tsx:64` `  parent.postMessage({ builderPreviewKey: { key: e.key, code: e.code, ctrlKey: e.ctrlKey, metaKey: e.metaKey, shiftKey: e.shiftKey, altKey: e.altKey } }, '*');` — Início: a página do preview envia a tecla premida ao editor, pela janela mãe.
2. `src/editor/shell/preview.tsx:62` `  var leave = e.key === 'Escape' || (e.key === 'Enter' && (e.ctrlKey || e.metaKey));` — só Escape ou Enter com Ctrl ou Cmd são relaya.
3. `src/editor/shell/preview.tsx:63` `  if (!leave || (e.key === 'Escape' && document.querySelector('dialog:modal'))) return;` — uma tecla que não sai do preview, ou um Escape com um diálogo modal aberto na página, não é enviado.
4. `src/editor/shell/preview.tsx:75` `const withKeyRelay = (html: string): string => (html.includes('</body>')` — o script do relay entra no HTML exportado da página (a linha completa escreve o `KEY_RELAY` antes de `</body>` e, sem ele, ao fim).
5. `src/editor/shell/preview.tsx:32` `  const html = useMemo(() => withKeyRelay(previewPage(document, MODEL_RULES, page, siteScripts)), [document, page]);` — o HTML com o script é memoizado para o documento e a página abertos.
6. `src/editor/shell/preview.tsx:53` `      <iframe ref={frame} className="preview__page" data-region="preview-page" title={t('preview.pageLabel')} srcDoc={html} sandbox="allow-scripts allow-popups allow-forms allow-popups-to-escape-sandbox" style={{ width }} />` — a moldura do preview corre a página com o script; a mensagem que ela envia é ouvida em ENT-L09b-0014.

## Ramos
- `src/editor/shell/preview.tsx:62` `  var leave = e.key === 'Escape' || (e.key === 'Enter' && (e.ctrlKey || e.metaKey));` — Escape ou Enter com Ctrl ou Cmd: relaya; outra tecla: não.
- `src/editor/shell/preview.tsx:63` `  if (!leave || (e.key === 'Escape' && document.querySelector('dialog:modal'))) return;` — com um diálogo modal aberto na página, o Escape é a página que o fecha e não é enviado; sem ele, segue.

## Fronteiras assíncronas
- `src/editor/shell/preview.tsx:61` `const KEY_RELAY` — o script do relay, com o ouvinte de `keydown` que a página instalada registra; dispara a cada tecla premida no preview e termina no `postMessage` do passo 1; entre a instalação e o disparo a página corre por si no seu próprio documento.
