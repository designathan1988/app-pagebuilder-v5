# ENT-L06-0074 — runtime de formulários: retomada depois de enviar o formulário

A submissão de um formulário do runtime com destino que não é `native` envia os dados ao endereço configurado; a promessa do `fetch` resolve com a resposta HTTP e o formulário mostra o resultado.
