# ENT-L06-0071 — runtime de formulários: instalação dos ouvintes no documento

A função `listen` do runtime de formulários registra cada ouvinte num nó do documento e guarda o limpador junto, para que a desmontagem os remova. É por ela que correm os ouvintes de composição, de entrada, de perda de foco e de submissão.
