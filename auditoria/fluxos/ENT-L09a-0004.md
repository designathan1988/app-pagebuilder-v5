## Ramos
- `src/editor/shell/batch-rename.tsx:49` `    if (!door.available) return;` — com a porta indisponível o tratador retorna sem despachar; com ela disponível segue.
- `src/editor/shell/batch-rename.tsx:52` `    const args = { ...apply.door.args, pattern: String(form.get('pattern') ?? ''), start: typed === '' ? Number.NaN : Number(typed) };` — com o primeiro número vazio, `start` é `NaN`; com um número digitado, é `Number(typed)`.
- `src/editor/shell/batch-rename.tsx:55` `      if (outcome.status === 'done' && CLOSE !== undefined) (store.dispatch as (id: CommandId, a: unknown) => DispatchResult)(CLOSE.command.id as CommandId, CLOSE.door.args);` — com o resultado `done` o diálogo é fechado; com outro resultado o diálogo fica aberto.

## Fronteiras assíncronas
- `src/editor/shell/batch-rename.tsx:53` `    afterGesture(store, () => {` — quando um gesto está aberto, `afterGesture` adia o despacho para um quadro seguinte `src/editor/input/pointer/common.ts:408` `  const wait = () => (shared.open === null ? run() : requestAnimationFrame(wait));`, pelo que outra entrada da área pode rodar no intervalo; o estado é o de um gesto de ponteiro aberto.

## Estado
- lê: EST-L09a-005 (o padrão, via `form.get('pattern')`); EST-L09a-006 (o primeiro número, via `form.get('start')`).
- escreve: EST-L01-030 (o documento, via dispatch), EST-L01-037 (o estado do editor, via dispatch).

## Resultado
- **Estado final:** o documento recebe os novos nomes dos elementos selecionados (`element.renameMany`) e o diálogo fecha `src/editor/shell/batch-rename.tsx:55` `      if (outcome.status === 'done' && CLOSE !== undefined) (store.dispatch as (id: CommandId, a: unknown) => DispatchResult)(CLOSE.command.id as CommandId, CLOSE.door.args);`.
- **Re-renderizado:** a árvore do editor re-renderiza com os nomes novos e o diálogo deixa de ser desenhado quando `ui.dialog` deixa de ser `batch-rename`.
- **DOM do editor:** os nomes nas Camadas e nos rótulos mudam; o diálogo sai do ecrã.
- **DOM do canvas:** a página do iframe é redesenhada com os nomes novos dos elementos.
