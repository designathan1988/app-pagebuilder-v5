# ENT-L06-0054 — fluxo SSE: ouvinte do aborto do sinal

O gerador `parseEvents` registra no sinal um ouvinte de `abort` que cancela a leitura do fluxo. É o caminho pelo qual um cancelamento do assistente interrompe a leitura do fluxo do provedor.

## Passos
1. `src/editor/assistant/stream.ts:19` `signal?.addEventListener('abort', abort, { once: true });` — registra o ouvinte `abort` no sinal, uma vez só.
2. `src/editor/assistant/stream.ts:16` `const abort = () => {` — a função que roda no aborto.
3. `src/editor/assistant/stream.ts:17` `void reader.cancel(signal?.reason);` — cancela o leitor do fluxo com o motivo do sinal.
4. `src/editor/assistant/stream.ts:23` `const { value, done } = await reader.read();` — a leitura em curso, que o cancelamento faz resolver.

## Ramos
- R1 `src/editor/assistant/stream.ts:19` `signal?.addEventListener('abort', abort, { once: true });` — sem sinal (chamada sem `signal`), nenhum ouvinte é registrado; com sinal, o ouvinte é registrado.
- R2 `src/editor/assistant/stream.ts:17` `void reader.cancel(signal?.reason);` — o motivo do sinal é passado ao cancelamento quando existe; sem motivo, `undefined`.

## Fronteiras assíncronas
- `src/editor/assistant/stream.ts:19` `signal?.addEventListener('abort', abort, { once: true });` — o ouvinte roda quando o sinal é abortado; no intervalo entre o registro e o aborto o gerador lê o fluxo em `ENT-L06-0055`, e o estado da aplicação é o de um turno em curso (EST-L06-013 com `active`).
