# ENT-L09a-0138 — ouve o foco dentro do campo de origem

O efeito de montagem de `useFocusWithin` (`src/editor/shell/field-origin.tsx`) inscreve os ouvintes de foco do documento para saber se o foco está dentro do campo cuja porta é esta.

3. `src/editor/shell/field-origin.tsx:25` `    const update = () => setFocused(focusInside(ref));` — o callback lê o foco do documento e grava o estado. [lê: EST-L09a-082 via focusInside] [escreve: EST-L09a-081 via setFocused]

## Ramos
- R1 `src/editor/shell/field-origin.tsx:21` `const focusInside = (ref: string) => document.activeElement instanceof Element` — o foco está dentro do campo quando o elemento ativo é um `Element` que casa com a porta; sem elemento ativo, `focusInside` é falso.
- R2 `src/editor/shell/field-origin.tsx:32` `  }, [ref]);` — a porta diferente reincreve os ouvintes; a mesma porta os mantém.

## Fronteiras assíncronas
- `src/editor/shell/field-origin.tsx:26` `    document.addEventListener('focusin', update);` — o ouvinte de foco que entra: dispara a cada foco no documento; entre a inscrição e o disparo qualquer entrada da área L09a pode rodar.
- `src/editor/shell/field-origin.tsx:27` `    document.addEventListener('focusout', update);` — o ouvinte de foco que sai: dispara a cada saída de foco no documento. O estado é o foco do navegador (EST-L09a-082) e o próprio `focused` (EST-L09a-081).
